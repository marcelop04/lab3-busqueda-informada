# Laboratorio N° 3: Búsqueda informada con Greedy Best-First Search y A*

Este repositorio contiene la solución al Laboratorio 3 del curso de Inteligencia Artificial.

## Estructura de archivos
- `Lab3_Palacios_Marcelo.ipynb`: Cuaderno principal con todo el código ejecutado.
- `datos/`: Carpeta con los 4 archivos CSV requeridos para el grafo y las heurísticas.
- `ponderado`: Contiene la gráfica generada por A* ponderado.

## Instrucciones de ejecución
Para ejecutar el código correctamente usando Google Colab:
1. Abra el archivo `.ipynb` en Google Colab.
2. En el panel izquierdo de Colab, cree una carpeta llamada `datos`.
3. Suba los cuatro archivos `.csv` (ubicados en la carpeta `datos` de este repositorio) dentro de la carpeta `datos` de Colab.
4. Vaya a `Entorno de ejecución` > `Ejecutar todas`.
5. El código instalará automáticamente `matplotlib` si es necesario y generará las tablas y gráficas requeridas.
